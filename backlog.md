Ping de internet: Un indicador numérico en milisegundos para ver la latencia real.

Selector trimodal: Un control para cambiar entre los modos Código, Diseño y Documentos.

Switch del túnel: Un botón para pausar o reanudar el túnel de Cloudflare al instante.

Caja de URL: Un campo con la URL pública activa de Cloudflare y un botón para copiarla.

Rama de Git: Un texto que muestre el nombre de la branch activa en la que estás trabajando.

Monitor de RAM/VRAM del modelo: Un medidor exclusivo de los GB de memoria ocupados por llama.cpp en la GPU con Metal.

Métricas de hardware: Gráficos en tiempo real del uso general de CPU, GPU y Disco de la máquina.

Barra de contexto segmentada: Una barra de progreso que divida el uso de los 16,384 tokens (Prompt de sistema, archivos inyectados, historial de chat y espacio libre).

RPM y RPS Cloud: Gráficas para medir las peticiones por minuto y por segundo enviadas a la nube.

Distribución de modelos: Una gráfica que muestre el porcentaje de tareas resueltas de forma Local frente a Cloud.

Contador de ahorro: Una métrica que calcule los dólares ahorrados en comparación con Claude Code.

Temporizador del agente: Un indicador que muestre cuánto demora la IA en procesar la información de extremo a extremo.

Mapeo de caché: Telemetría integrada para mostrar los Cache Hits y Cache Misses de los tokens.

Diseñador de requerimientos: Un panel visual donde el modelo local convierte la transcripción de voz en una lista estructurada de requerimientos técnicos.

Inspector de payload: Un visor interactivo del JSON de requerimientos antes de mandarlo a la API Cloud.

Consola de sincronización Git: Un indicador visual que confirme que se ejecutaron automáticamente los comandos git fetch y git pull al iniciar la tarea.

Árbol de cambios de la sesión: Una lista lateral interactiva con los archivos modificados, creados o eliminados por el agente.

Pestaña dedicada de Diff: Una pantalla exclusiva para revisión de código que muestre de forma exacta las líneas quitadas en rojo (-) y las líneas agregadas en verde (+).

Formulario de confirmación obligatoria: Campos que exijan escribir la branch y el mensaje del commit antes de permitir que la IA guarde los cambios físicamente en el disco.

Bóveda de API Keys: Campos ocultables para tus credenciales Cloud con un validador asíncrono en tiempo real (ping de confirmación).

Descargador de modelos locales: Un gestor de archivos GGUF que muestre el porcentaje de descarga y la velocidad real en MB/s.

Configurador Codegraph: Ajustes para activar y gestionar el mapa semántico del repositorio para ahorrar contexto.

Matriz de permisos MCP: Una tabla de switches para elegir qué acciones se auto-aprueban y cuáles requieren confirmación obligatoria en el Hub.

Soporte MCP de terceros: Capacidad lógica para conectar, registrar y consumir herramientas de servidores MCP externos (como GitHub, Brave Search, etc.).
